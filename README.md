# 67-vpn

## Описание проекта
Данный репозиторий содержит скрипты и конфигурации для развертывания защищенного VPN-сервера на базе WireGuard с изоляцией DNS-запросов. Выполнено в рамках практической работы (Командное задание).

## Структура
- `configs/wg0.conf` — шаблон конфигурации сервера WireGuard с правилами NAT.
- `scripts/deploy_vpn.sh` — bash-скрипт для автоматической установки пакетов и включения форвардинга.
- `scripts/test_dns.sh` — bash-скрипт для проверки туннеля и симуляции тестирования на утечки DNS (Пункт 6).

## Использование
1. Запустите `deploy_vpn.sh` на сервере (требуются права root).
2. Заполните `wg0.conf` сгенерированными ключами и поместите в `/etc/wireguard/`.
3. Запустите интерфейс: `systemctl start wg-quick@wg0`.
4. На стороне клиента запустите `test_dns.sh` для проверки.
